## 一、服务内容与软件性质

本应用是开源订阅管理工具 Sub-Store（https://github.com/sub-store-org/Sub-Store ）的 HarmonyOS 客户端：在您的设备上本地运行 Sub-Store 后端与管理界面，提供订阅的添加、组合、节点操作（筛选、重命名、排序、脚本等）和格式转换（Surge、Loon、Quantumult X、Stash、Clash / mihomo、sing-box、Shadowrocket、v2rayN 等），并在本机或局域网提供订阅下载的 HTTP 服务。本应用的服务、端口、后台运行、外观与访问密码等功能由我们开发；Sub-Store 的功能与界面来自其开源项目，我们只做了适配本应用运行环境的必要修改。

**本应用只是一个在您设备上运行的本地工具，不提供、不内置、不出售、不推荐任何代理服务器、节点、订阅、账号、VPN、网络加速、翻墙或其他网络接入服务，不运营任何服务器，不提供任何网络内容，也不连接任何代理网络。** 本应用中的订阅与节点均由您自行添加，生成的订阅需要配合其他代理客户端使用。我们与任何节点或订阅的提供者不存在合作或利益关系，与 Sub-Store 项目及其作者也不存在隶属、授权、赞助或合作关系。

## 四、本机服务、脚本与数据安全

- 服务默认只监听 127.0.0.1（仅本机可访问），使用不加密的 HTTP，**Sub-Store 后端没有登录验证**。开启“允许局域网访问”后，同一网络中的设备可以下载订阅链接；开启“局域网也可打开管理界面”后，同一网络中的任何设备都能查看、修改或删除您的 Sub-Store 数据。**是否开启、在什么网络中开启、向谁提供订阅链接，由您自行决定并承担风险。** 同一设备上的其他应用也可以访问 127.0.0.1 上的服务。
- 订阅内容包含节点的密码和密钥。您应妥善保管订阅链接、分享令牌、导出的文件、备份文件与同步令牌，不要分享给不信任的人。**因链接、令牌或文件泄露造成的后果由您自行承担。**
- Sub-Store 可以运行您添加的脚本。脚本在本机运行、可访问网络并处理您的订阅内容，**请只使用您信任的脚本，由脚本造成的后果由您自行承担。** 本应用内置的 JavaScript 引擎与 Node.js 等官方运行环境存在差异，个别依赖 Node.js 专有能力的功能（如部分网络探测、GeoIP 数据库）可能不可用或表现不同。
- HarmonyOS 可能在应用切到后台后暂停或结束服务（即使已申请长时任务），我们不对由此造成的订阅更新失败负责。
- **数据只保存在您的设备上，我们无法备份或找回。** 卸载应用、清除数据、更换或重置设备、系统故障或误操作都可能导致数据永久丢失，请定期使用 Sub-Store 的备份功能。我们不对数据丢失承担责任。
