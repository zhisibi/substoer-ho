# 咪咪SubStore 隐私政策

更新日期：2026 年 10 月 30 日（第 1 版）

开发者：张世博（以下简称“我们”）。联系方式：问题反馈 QQ 群 1127250124。

咪咪SubStore（以下简称“本应用”）是一款在本机运行的订阅管理与格式转换工具。我们非常重视您的隐私：本应用的设计原则是**不收集个人信息、数据只保存在您的设备上**。请在使用前仔细阅读本政策。

## 一、我们收集的信息

- **我们不收集任何个人信息。** 本应用无需注册或登录，没有账号体系；不收集姓名、电话、设备标识符、位置、使用行为或崩溃数据；未集成任何统计、广告、推送或崩溃上报等第三方 SDK。
- **您主动保存的数据：** 您在本应用中添加的订阅、组合订阅、文件、脚本、同步配置与应用设置，只保存在本应用在您设备上的私有目录中（沙箱内，文件权限受限），不会上传或发送给我们，我们也无法访问。
- **运行日志：** 服务的访问记录（来访 IP、请求路径、User-Agent、状态码）与运行事件只保存在内存中，退出应用即清除；日志中的敏感参数（如订阅链接中的 token）在记录前会脱敏。日志仅在您主动点按“复制”或“保存为文件”时离开应用，发送对象由您决定。

## 二、网络连接

本应用只会连接以下地址，且均由您的操作或配置触发：

- 您自行添加的远程订阅、脚本、规则与同步服务地址（用于拉取您订阅的内容）；
- 本项目的 GitHub 仓库（github.com、api.github.com 及 GitHub 的下载域名），仅在您检查/执行“Sub-Store 更新”“检查应用更新”，或开启了“启动时检查更新”时访问；按您选择的下载线路，可能经 ghfast.top、gh-proxy.com 等公共加速服务转发。上述请求不包含您的订阅数据，但相关服务会按其各自的隐私政策处理您的 IP 地址；
- 您开启“允许局域网访问”后，本应用在局域网内提供订阅下载服务，访问范围由您控制。

## 三、权限说明

| 权限 | 用途 | 是否可关 |
| --- | --- | --- |
| 网络访问（INTERNET） | 拉取您添加的远程订阅与检查更新 | 系统设置中可关，关闭后远程功能不可用 |
| 获取网络信息（GET_NETWORK_INFO） | 显示本机局域网地址 | 系统设置中可关 |
| 后台运行（KEEP_BACKGROUND_RUNNING） | 您开启“后台继续运行”时保持本机服务 | 在应用内关闭该开关即停用 |

本应用不申请相机、麦克风、位置、通讯录、短信、存储读写等权限。剪贴板只在您点按复制按钮时写入，不会读取；文件只通过系统文件选择器由您主动挑选和保存。

## 四、信息的存储与安全

- 数据存储于应用沙箱的私有目录，存储期限为您在本应用中保留期间；卸载应用或在“服务管理 → 关于 → 清除全部数据”后即全部删除（清除数据同时会删除已下载的组件更新）。
- 需要说明：订阅内容（含节点密码等凭据）在本机以应用数据形式保存，未做额外加密，请妥善保管您的设备与备份文件；本机服务使用 HTTP 且后端无登录验证，请勿在不可信网络中开启局域网访问。

## 五、第三方共享与转让

- 我们不会向任何第三方出售、共享或转让您的信息，因为我们并不持有您的信息。
- 例外：您自行配置的同步服务（如 GitHub Gist）由 Sub-Store 后端按您的配置直接通信，数据的处理适用该服务自身的隐私政策。

## 六、您的权利

- 您可以随时在本应用中查看、修改、导出或删除您的全部数据（Sub-Store 的备份/导出功能与“清除全部数据”）。
- 您可以撤回同意：进入“服务管理 → 关于 → 撤回同意”，服务将停止且应用退出，再次打开需重新同意；撤回不影响您数据的保留与否，删除请用“清除全部数据”或卸载。
- 如对本政策有疑问，可通过文首联系方式与我们联系。

## 七、未成年人

本应用面向成年用户，未满 18 周岁的未成年人请勿使用。

## 八、政策更新

本政策更新后，应用会在启动时提示并请您重新确认；更新版本与日期会标注在本页顶部。
