# 咪咪SubStore 隐私政策

更新日期：2026 年 10 月 22 日（第 1 版）
生效日期：2026 年 10 月 22 日

咪咪SubStore（以下简称“本应用”）由个人开发者张世博（以下简称“我们”）开发和提供。本应用是开源订阅管理工具 Sub-Store 的 HarmonyOS 客户端：Sub-Store 的后端和管理界面都在您的设备上本地运行，用于管理和转换您自己的代理订阅（如 Surge、Loon、Quantumult X、Stash、Clash / mihomo、sing-box 等格式），并在本机或您的局域网中提供订阅下载。**本应用只是一个本地工具，本身不提供任何代理服务器、节点、订阅、VPN 或翻墙服务，也不提供任何网络内容。**

我们深知个人信息对您的重要性，并按照《中华人民共和国个人信息保护法》等法律法规的要求处理信息。本政策说明本应用会处理哪些信息、如何处理以及您享有的权利，第十条说明与隐私相关的免责事项。请您在使用本应用前仔细阅读，特别是加粗的内容。本政策与《咪咪SubStore 用户协议》共同构成您使用本应用的规则。

## 一、我们收集的信息概览

1. 本应用**无需注册或登录，没有账号体系**。
2. 本应用**不收集、不上传**任何个人信息、设备标识符（如 OAID、UDID）、位置信息、通讯录、使用统计或行为数据，不进行用户画像、个性化推荐或广告追踪。
3. 我们**不运营任何为本应用提供数据服务的服务器**，您在本应用中保存的信息不会发送给我们。

## 二、仅保存在您设备上的信息

以下信息由您主动填写、导入或产生，**保存在本应用的私有沙箱目录中**，不会发送给我们：

1. Sub-Store 数据：您添加的单条订阅与组合订阅（名称、订阅链接或本地节点内容、User-Agent、节点操作与脚本、图标等）、文件、同步配置（如 GitHub Gist 令牌，仅在您填写时保存）、分享令牌、归档与 Sub-Store 设置，以及 Sub-Store 为加速而缓存的远程订阅与脚本内容。节点信息可能包含服务器地址、端口、UUID、密码与密钥。
2. 应用设置：主题、主题色、背景图片副本、界面语言、服务端口、是否允许局域网访问、后台运行与自动启动选项等。
3. Sub-Store 界面的本地存储：管理界面在内置网页组件中保存的偏好（如界面语言、显示选项），只存在本应用的网页数据目录中。
4. 运行日志：服务的运行事件（启动、停止、端口错误、后台任务）、Sub-Store 后端输出的日志，以及订阅下载和来自其他设备的请求记录（时间、来访 IP、路径、状态、客户端 User-Agent），仅保存在内存中（最多 2000 条），用于在“服务”页显示，应用退出后即清除。
5. 访问密码与密保（可选）：如果您设置了应用访问密码，本应用**不保存密码和密保答案本身**，只保存它们的加盐哈希值（PBKDF2-HMAC-SHA256，每项使用独立的随机盐）以及密保问题文字，存放在系统 Asset Store（资产存储）中，仅本应用可读。我们和任何人都无法从哈希值还原您的密码。
6. 系统日志：应用运行信息写入系统日志（hilog）用于开发调试，本应用不会读取或上传。

## 三、网络访问与权限

| 权限 | 用途 |
| --- | --- |
| 网络（ohos.permission.INTERNET） | 运行本机 Sub-Store 服务；拉取您添加的远程订阅、脚本和规则；访问您配置的同步服务；在本机或局域网提供订阅下载 |
| 网络状态（ohos.permission.GET_NETWORK_INFO） | 读取本机的局域网 IP 地址，用于显示局域网订阅地址 |
| 后台运行（ohos.permission.KEEP_BACKGROUND_RUNNING） | 仅在您开启“后台继续运行”并启动服务时，向系统申请长时任务，使服务在应用切到后台后继续响应 |
| 生物识别（ohos.permission.ACCESS_BIOMETRIC） | 仅在您设置访问密码并开启“指纹解锁”后，调用系统指纹认证解锁本应用 |

1. 本应用的对外网络连接**只发往您在 Sub-Store 中添加或配置的地址**：远程订阅链接、脚本与规则地址、您启用的同步服务（如 GitHub Gist）。Sub-Store 管理界面中的部分图片（如空白页插图、图标）可能从其开源项目使用的公共图床加载，这些请求不包含您的订阅数据。**Sub-Store 组件更新：** 您在“设置 → Sub-Store 更新”中点“检查更新”、“立即更新”，或保持“启动时检查更新”开启（每天最多一次）时，本应用会从本应用的 GitHub 开源仓库（github.com/zhisibi/substoer-ho）下载更新清单和文件；按您选择的下载线路，也可能经 ghfast.top、gh-proxy.com 等公共加速服务转发。这些请求只包含应用版本标识，不包含您的订阅数据。除此之外，本应用不会连接我们的服务器。
2. **本机服务**默认只监听 127.0.0.1（仅本机可访问），端口默认 3000。开启“允许局域网访问”后，同一局域网内的设备**只能访问订阅下载链接（/download、/share）**；只有您另外开启“局域网也可打开管理界面”时，其他设备才能打开管理界面并调用后端接口。**Sub-Store 后端没有登录验证，订阅内容包含节点的密码和密钥，请只在可信的网络中开启局域网访问，不要把订阅链接分享给不信任的人。** 服务使用 HTTP（不加密），同一网络中的他人可能截获传输内容。
3. 本应用**不申请相机、麦克风、位置、通讯录、存储等权限**。

## 四、设备能力的使用

1. 剪贴板：只有您在 Sub-Store 界面中点按“复制”等操作时才写入剪贴板；本应用不会自动读取剪贴板。
2. 文件：在 Sub-Store 中还原备份、导入文件时，通过系统选择器由您挑选文件；下载备份或导出配置时，通过系统“另存为”由您指定位置。**备份和导出的文件可能包含明文密码与密钥，请妥善保管。**
3. 打开其他应用或网页：在 Sub-Store 中点按指向其他网站或客户端导入链接（如 clash://、sing-box://）的按钮时，由系统打开浏览器或对应应用；接收方如何处理这些信息，由其自身的隐私政策约定。
4. 长时任务与通知：开启后台运行后，服务运行期间系统会显示常驻通知；停止服务后通知消失。
5. 指纹解锁：指纹的录入、比对和存储完全由 HarmonyOS 系统用户认证服务在设备安全环境中完成，**本应用无法获取、也不保存任何指纹图像或特征数据**。

## 五、第三方 SDK、开源组件与第三方服务

1. 本应用**未集成任何第三方 SDK**（包括统计、广告、推送、登录、崩溃上报类 SDK）。
2. 本应用内置开源项目 Sub-Store 的后端与管理界面（见《用户协议》开源软件声明），它们在您的设备本地运行，不会向其作者或我们发送数据。
3. 您在 Sub-Store 中配置的第三方服务（订阅服务商、脚本托管、GitHub Gist 等）由第三方按其政策处理您的请求。
4. 检查更新仅在您点击“设置 → 关于 → 检查更新”时通过华为应用市场查询，由华为按其隐私政策处理。

## 六、信息的存储、保存期限与安全

1. 存储地点：上述信息只保存在您的设备上。
2. 保存期限：信息保存到您在应用内删除，或卸载本应用为止；运行日志在应用退出后清除。
3. 安全措施：数据存放在系统为本应用分配的私有沙箱中，其他应用无法读取；服务默认只监听本机地址，其他设备默认无法访问管理接口；可设置应用访问密码与指纹解锁。请您妥善保管设备并设置锁屏密码。需要注意，同一设备上的其他应用可以访问 127.0.0.1 上的本机服务。

## 七、自启动与关联启动

1. 本应用不会开机自启动，不会在后台被其他应用唤起。“打开应用时自动启动服务”仅在您手动打开本应用时生效（管理界面需要该服务），可在“服务”页关闭。
2. 本应用只在您主动点按时打开其他应用或网页。

## 八、您的权利

1. 查阅与更正：您可以在 Sub-Store 界面和应用设置中随时查看、编辑您保存的信息。
2. 删除：您可以在 Sub-Store 中逐项删除，或使用“设置 → 数据与隐私 → 清除全部数据”一次性删除全部 Sub-Store 数据；卸载本应用会删除全部数据。
3. 撤回同意：您可以在“设置 → 数据与隐私 → 撤回隐私政策同意”中撤回同意，撤回后应用将停止服务并退出，再次使用需要重新同意；撤回不影响此前基于同意已进行的处理。
4. 由于我们不持有您的任何信息，无需注销账户。

## 九、未成年人保护

本应用面向年满 18 周岁、具有完全民事行为能力并具备网络管理能力的成年用户，**未满 18 周岁的未成年人请勿下载、安装或使用本应用**。本应用不收集任何个人信息，也无从识别使用者的年龄。如您是监护人并发现未成年人使用了本应用，可以指导其清除数据并卸载本应用，或通过下方邮箱联系我们。
