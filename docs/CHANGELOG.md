# 更新日志

## 1.4.0

- 外观新增「主题色」与「背景」（与咪咪SSH / 咪咪面板同款）：主题色六种——华为红（默认）、靛青、薄荷青、天空蓝、优雅紫、琥珀橙，同时作用于原生页面（强调色/按钮渐变）和网页界面（--primary-color 系列变量）；背景五种——纯色（默认）、极光、深海、暮霞、林间，渐变绘制在页面底层、卡片转半透明透出，原生与网页界面同步。

## 1.3.2

- 网页底部导航栏的沉浸光感升级为咪咪SSH 同款玻璃效果：底栏改为悬浮玻璃胶囊（四周留边、30vp 圆角、悬浮投影），强背景模糊+饱和度提升、染色渐变、斜向镜面光泽，以及与原生 LightSense 相同的双层光边（顶部亮边+内侧柔光）；深色模式自动换深色玻璃。

## 1.3.1

- 修复「导航栏沉浸光感」在主界面无效：主界面的底部导航栏属于网页前端（NutUI tabbar），原生玻璃材质作用不到——开启时改为向网页注入光感样式，底栏呈毛玻璃透光（backdrop blur + 顶部光边），深色模式自动适配；开关与主题切换即时生效，页面加载后自动补注。原生页面顶栏的悬浮玻璃胶囊不变。
- 修复 ArkTS 严格模式编译错误（LegalPage 读取路由参数需显式类型）。
